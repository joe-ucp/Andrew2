# Post-review one-to-one identifier sensitivity

This sensitivity is separate from the frozen exact-symbol primary analysis. It tests how a bounded, documented crosswalk changes the catalogue; it does not silently repair the primary. Run `python code/audit_identifier_mapping.py`. Source reconstruction is independent of the main analysis; inference uses the tested `exact_stats.py` helper.

The official HGNC complete set was downloaded from the [HGNC download service](https://www.genenames.org/download/) on 2026-10-23. The saved response's Last-Modified is 2026-10-16 13:36:15 GMT. The 16,982,321-byte input is pinned by SHA-256 `12363916be36f8f6f91879b0faade4eeaac973722de7136ec61329b77f2c2f91`; retrieval metadata is in `data/source_documents/hgnc_retrieval.json`. This is a fixed retrieved snapshot, not an assertion that the current download will remain identical. HGNC data are [CC0](https://hgnc.genenames.org/about/license/).

An exact approved symbol takes precedence. Otherwise, the union of previous and alias symbols must resolve to exactly one approved HGNC ID. A source with multiple distinct symbols resolving to the same HGNC ID has all colliding mappings excluded. Expression is linked using the workbook's Ensembl GeneID and the HGNC Ensembl field; only a unique match is retained, with explicit rejection if the source symbol has a unique contradictory mapping. Terminal numeric Ensembl version suffixes would be removed and recorded; no other identifier edits are made. Multiple expression rows per HGNC ID are excluded. Unmapped and ambiguous cases remain excluded, with reasons in the ledger.

The source survival/guide-coverage rules and expression baseMean >=10 threshold are retained. The insulin label comes from published Table S1 only. Expression quintiles are recomputed within this altered universe, using right-closed linear quantile bins; guide strata remain survival 3–5/6+ and insulin 3/4+. Thus this changes the universe and corresponding stratification, not only a display name.

The result is N=12,826, A=306, L=510, overlap=14; conditional OR 1.14436 (exact 95% CI 0.61241–1.97349), upper-tail p=0.35367. The interval spans 1. Relative to exact-symbol primary membership, 704 survival source symbols enter and 62 leave. The same overlap count does not mean the same candidate membership.

NUPL1 resolves uniquely to HGNC:20261, approved symbol NUP58. The source expression row is 20698, GeneID ENSG00000139496, GeneName NUP58; it enters the sensitivity. SLC8B1 leaves because D1 contains both SLC8B1 and SLC24A6, which resolve to HGNC:26175. The declared within-source collision rule excludes both rather than choosing or combining their screen estimates. C12orf29 is retained with approved symbol RLIG1 while preserving its original labels in the ledger and analysis rows.

`results/identifier_sensitivity/mapping_ledger.csv` records each source mapping and exclusion. `stable_id_primary_genes.csv` retains all source symbols and IDs alongside approved symbols and inference labels; `stable_id_primary_strata.csv` gives the twenty conditional margins. `evidence/identifier_mapping_sensitivity.json` records the exact estimates, source/code/output hashes, mapping-disposition counts, membership changes and candidate identities. This remains a post-review sensitivity with explicit selection limits; it does not override the published primary table.
